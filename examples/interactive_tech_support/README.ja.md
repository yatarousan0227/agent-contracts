# インタラクティブ テックサポート デモ

agent-contractsを使用したマルチノードテックサポートアシスタントの構築を示す包括的なサンプルです。インタラクティブCUIとオプションのLLM統合を備えています。

## 概要

このサンプルは以下の機能を持つ**テックサポートアシスタント**を作成します：
- ユーザーの質問を専門サポートエージェント（ハードウェア、ソフトウェア、ネットワーク、一般）にルーティング
- ルールベースとLLMベースの両方のルーティングを実演
- ハードコードされたFAQ/ナレッジデータを使用してスタンドアロンで動作
- LLMプロバイダー設定を備えたインタラクティブCUIを提供
- コントラクト駆動開発の明確なメリットを提示

## クイックスタート

```bash
# プロジェクトルートから実行
python -m examples.interactive_tech_support
```

## 機能

### スペシャリストノード

| ノード | カテゴリ | 説明 |
|------|----------|-------------|
| `HardwareNode` | ハードウェア | プリンター、モニター、キーボード、マウス、USB、電源の問題を処理 |
| `SoftwareNode` | ソフトウェア | クラッシュ、エラー、インストール、アップデート、マルウェアを処理 |
| `NetworkNode` | ネットワーク | WiFi、インターネット、VPN、DNS、ルーターの問題を処理 |
| `GeneralNode` | FAQ | 一般的な技術的質問とFAQ項目を処理 |
| `ClarificationNode` | 明確化 | 問題が不明確な場合に明確化のための質問を行う |

### ルーティング

アシスタントは2層のルーティングシステムを使用します：

1. **ルールベースルーティング**: ユーザーのメッセージ内のキーワードを事前定義されたパターンと照合
2. **LLMベースルーティング**: ルールがマッチしない場合、オプションのLLMがセマンティックルーティング判断を行う

### CLIコマンド

| コマンド | 説明 |
|---------|-------------|
| `/help` | 利用可能なコマンドを表示 |
| `/setup` | LLMプロバイダーを設定 |
| `/status` | 現在の設定を表示 |
| `/debug` | デバッグモードを切り替え（ルーティング情報を表示） |
| `/clear` | 会話履歴をクリア |
| `/exit` | アプリケーションを終了 |

## LLMプロバイダーサポート

このサンプルは複数のLLMプロバイダーをサポートしています：

| プロバイダー | 必要なパッケージ | 環境変数 |
|----------|-----------------|---------------------|
| OpenAI | `langchain-openai` | `OPENAI_API_KEY` |
| Azure OpenAI | `langchain-openai` | `AZURE_OPENAI_API_KEY`, `AZURE_OPENAI_ENDPOINT` |
| Anthropic | `langchain-anthropic` | `ANTHROPIC_API_KEY` |
| Google AI | `langchain-google-genai` | `GOOGLE_API_KEY` |
| Ollama | `langchain-ollama` | （ローカル、APIキー不要） |

### LLMプロバイダーのインストール

```bash
# OpenAI用
pip install langchain-openai

# Anthropic用
pip install langchain-anthropic

# Google AI用
pip install langchain-google-genai

# Ollama用
pip install langchain-ollama
```

## このサンプルが示す内容

| 機能 | 実演内容 |
|---------|--------------|
| **コントラクト** | 各スペシャリストノードの明確なI/O定義 |
| **ルーティング** | ルールベース（キーワード）とLLMベース（セマンティック）の両方 |
| **モジュール性** | 自己完結型ノード、新しいスペシャリストの追加が容易 |
| **設定** | YAMLベースの設定、LLMプロバイダーの柔軟性 |
| **可観測性** | デバッグモードでルーティング判断を表示 |
| **スタンドアロン** | ハードコードされたナレッジベースを使用してLLMなしで動作 |
| **インタラクティブ** | セットアップウィザードとコマンドを備えた完全なCUI |

## サンプルの拡張

### 新しいスペシャリストノードの追加

1. `knowledge/`に新しいナレッジベースを作成
2. `nodes/`に`NodeContract`を持つ新しいノードを作成
3. `cli/app.py`でノードを登録

### ナレッジベースエントリの追加

適切なナレッジベースファイルにエントリを追加してください：
- `knowledge/hardware_kb.py` （または `hardware_kb_ja.py`）: ハードウェアの問題用
- `knowledge/software_kb.py` （または `software_kb_ja.py`）: ソフトウェアの問題用
- `knowledge/network_kb.py` （または `network_kb_ja.py`）: ネットワークの問題用
- `knowledge/faq_data.py` （または `faq_data_ja.py`）: 一般FAQ項目用
